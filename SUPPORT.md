# Community support

Free-tier support is provided through GitHub issues and discussions on a best-effort basis. Before opening an issue, use the latest release, check existing reports, and include operating system, Python version, Vulcanary version, and a minimal synthetic reproduction.

Never attach proprietary source, live credentials, `.env` files, or unredacted scan output. Security vulnerabilities belong in GitHub private vulnerability reporting as described in `SECURITY.md`.

There is currently no paid support plan, uptime commitment, or service-level agreement.
